# Local technology marks

Node.js, PostgreSQL, RabbitMQ, Redis, Next.js, React, TypeScript, Docker, Ubuntu, Tailscale, Apple, pnpm and HTML5 marks come from [Simple Icons 16.0.0](https://github.com/simple-icons/simple-icons/tree/16.0.0/icons). Their paths and published hexadecimal brand colors are preserved. Simple Icons distributes that collection under [CC0](https://github.com/simple-icons/simple-icons/blob/16.0.0/LICENSE.md); trademark guidelines still belong to the respective owners.

Toxiproxy uses the mark linked by its [official project README](https://github.com/Shopify/toxiproxy), from [the linked PNG](https://i.imgur.com/sOaNw0o.png). `toxiproxy.svg` embeds that PNG locally. This asset is separate from the Simple Icons collection; the CC0 attribution above does not apply to it. Project/brand rights remain with its owner.

The console and every editable scene use these local files. Rendering makes no icon CDN requests. A mark identifies the actual implementation technology, not a vendor service added to the lab. Internal modules reuse their owner's technology mark; logical databases reuse PostgreSQL. macOS scopes use Apple, and the Ubuntu guest also shows Docker.

Regenerate all documented scenes with `node --import tsx tools/architecture-diagrams.mjs`, then export SVGs through Excalidraw 0.18.1. The compact backend-layout export is separately generated by `pnpm exec tsx tools/backend-diagram.ts`. Keep these assets, registry labels and [all eight drawings](../README.md) consistent. Public scenes contain architecture text only, without machine addresses, credentials or observed status.
